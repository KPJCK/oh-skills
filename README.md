# oh-skills

A Claude Code plugin bundling five personal dev-cycle skills: `oh-nice`, `oh-context`, `oh-search`, `oh-doctor`, `oh-help`.

Requires Bun. Configuration via `.oh-env` — see `templates/.oh-env.example`.

## Install

```
/plugin marketplace add chaiyawutk/oh-skills
/plugin install oh-skills
```

Then in a project:

```
/oh init
```
